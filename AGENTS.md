## Agent skills

### Issue tracker

Issues live in GitHub Issues for `Nabsku/pi-workflow-watcher`; use the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Use canonical triage labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `paused`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context repo: read root `CONTEXT.md` and root `docs/adr/` when present. See `docs/agents/domain.md`.
